
# EduQuery AI

EduQuery AI is an educational web application built using React.js and Vite, designed to provide an interactive learning experience.

## Live Demo

**Try the application:** [EduQuery AI](https://edu-query-ai-ydwj.vercel.app/)

The application is publicly accessible and requires no local installation.

## Tech Stack

- React.js
- JavaScript
- Vite
- CSS
- React Markdown

## Run Locally (Optional)

```bash
git clone https://github.com/Prashantfr/EduQuery-AI.git
cd EduQuery-AI
npm install
npm run dev
```

## Deployment

Deployed on Vercel.
